# 飞书来源图标

`lark.svg` 是 ByteDance IconPark 的 `new-lark`，通过 Iconify 分发取得：
https://api.iconify.design/icon-park/new-lark.svg

上游：https://github.com/bytedance/IconPark

图标代码按 Apache-2.0 复用，完整许可证保存在 `IconPark-LICENSE`。源文件保持不变；程序在深色主题下把黑色笔画转换为白色以保证对比度。本项目仅将其用于“在飞书中打开”的来源标识；飞书/Lark 商标归其权利人所有，不表示商标授权、官方合作或背书。
